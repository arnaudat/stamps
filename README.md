# STAMPS (Synchronized Temporal Analytics of Motion, Physiology, and Speech)

Code, configuration files, and post-processing scripts for the **STAMPS** platform (Synchronized Temporal Analytics of Motion, Physiology, and Speech).

This repository also hosts code related to the **Puzzle-STAMPS** dataset.

## STAMPS platform

STAMPS is a platform for recording and analyzing synchronized motion, physiological, and speech data. It was introduced in the Surg-STAMPS paper, published in the *IEEE Journal of Biomedical and Health Informatics*:
[https://ieeexplore.ieee.org/document/11651637](https://ieeexplore.ieee.org/document/11651637)

## Puzzle-STAMPS dataset

Puzzle-STAMPS is a multimodal dataset recorded with the STAMPS platform. It captures teams solving a series of physical puzzles and includes motion, physiological, audio, and video data.

- Dataset website: [https://puzzle-stamps.is.mpg.de/](https://puzzle-stamps.is.mpg.de/)
- The Puzzle-STAMPS paper has not been published yet. Citation details will be added here once it is.
